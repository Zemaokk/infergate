# Benchmark tools

These modules collect and report controlled HTTP experiments outside the
installed gateway runtime. Run them from the repository root.

- [Specification](../../docs/reference/benchmarks.md): profiles, validity, statistics, and artifacts.
- [Collect local measurements](../../docs/how-to/collect-local-benchmarks.md): pilot, formal run, invalid-case replacement.
- [Collect model measurements](../../docs/how-to/collect-model-benchmarks.md): GPU setup and native-protocol comparison.
- [Redraw saved measurements](../../docs/how-to/redraw-benchmarks.md): no-GPU reproduction.
- [Methodology](../../docs/explanation/benchmark-methodology.md) and [recorded results](../../docs/reference/validation.md#benchmark-results).
